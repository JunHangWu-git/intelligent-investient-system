# D. 择时-入场执行（开窗后的日K流程）

## 原始观点

材料强调入场流程"核心是等"，不追涨——错过了就等下一次。这与止损"是保险不是预测"的
态度一致：宁可少赚也不愿承担追高风险。绿柱日的判定被材料反复强调要"机械化"（严格按
规则找，不靠感觉），并列出三条反向禁令，说明这一步是历史上最容易凭直觉判断出错的地方。

## 核心原则

月K管方向（能不能关注）→ 日K管入场点（什么时候下手），顺序固定不可反：先等开窗，
再切日K找参考价，再等突破才买入。

## 判断流程（入场决策6步）

1. 状态A确认（月K双线+柱≥0轴）
2. 开窗后，次月切日K
3. 等日K高点+回撤
4. 用"绿柱日"算法确认回撤（见下方决策规则的机械定义）
5. 突破前高（参考价）= 买入，同时设止损（入场价-20%）
6. 切周K出场管理（周K低点动态出场，见F模块）

## 决策规则

**绿柱日机械定义（严格按此查找，不凭感觉）：**

从开窗次月（切日K月）第一个交易日起，按日期升序扫日K，取**柱<0交易日中日期最早者**。
只看柱的符号，不看幅度，不看是否"红转绿"事件，不判断是否连续成段（单日MACD柱<0即
成立，哪怕次日转红）；无论当月绿柱分几段、中间夹几根红柱，都取日期最早的柱<0交易日。
切日K月全月无柱<0 → 顺延至其后首个柱<0交易日。

**三条反向禁令（禁止用这些方法找绿柱日）：**
1. 禁止从月末/当前往回找
2. 禁止取"最近一次红转绿"事件日
3. 禁止取"离今天最近的一段绿柱"的起点

→ 绿柱日永远从切日K月第一天往后找第一个柱<0。

> 注：月K开窗判定用的"贴0轴不算数（\|柱\|<0.5）"规则不适用于这里——日K绿柱只看
> 符号，柱<0（哪怕只有-0.04）就是绿柱。

**参考价与突破：**
- 参考价 = [开窗月首日, 绿柱日] 闭区间日K最高（不看柱色）
- 突破 = 绿柱日后首个盘中high > 参考价，买入价按参考价记录
- 错过不追：超过参考价约5%不追，等下一次
- 50-60天不突破 → 入场失效

**复权口径选择（数据准备阶段的前置规则，写代码/查数据时必须显式指定）：**

| 场景 | 用哪种 |
|---|---|
| 问"现在/当前/近期/是否状态A/入场参考价"等现状判断 | 前复权（forward）——与行情软件当前显示一致 |
| 复盘/回测/历史区间/当时/上市以来/第一次入场/上次入场 | 后复权（backward）——历史口径固定不变 |
| 未明确表达"要回顾历史区间"的，一律 | 前复权（兜底原则：没说要回顾过去，就当看现在） |
| 同一次分析里历史事件+当前价并存 | 历史事件用后复权，当前价用前复权，分别注明，不能混用一个口径 |

> 判据是"有没有明确的历史区间意图"，不是看提问带没带年数字眼。若分析意图从"现状"
> 转到"历史区间"（或反向），必须用对应口径重新取数，不能复用已经拉取的数据。

## 常见错误

- 绿柱日按"最近一次红转绿"或"离今天最近的绿柱段起点"去找——两种都是明确禁止的
  错误取法，正确做法永远是从切日K月第一天往后扫，取最早的柱<0交易日
- 现状判断时用了后复权数据（或省略复权参数、误用脚本默认值）——会导致算出的当前价
  与实际行情软件对不上
- 突破后超过参考价5%还去追——材料明确"错过不追，等下一次"
- 50-60天窗口期过了还在等，没有判定入场已失效
