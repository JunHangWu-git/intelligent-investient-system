# B. 选股规则（企业质量·第一层概率优势）

## 原始观点

选股要解决的是"这家公司值不值得买"，不解决"什么时候买"——高分只说明基本面好，不代表
价格合适。材料强调"金字塔不替你选股，只帮你缩小范围"，即工具是筛选辅助，最终判断
（行业前景/竞争地位/风险点）仍需人工复核，不能全交给量化分数。

## 核心原则

同行业对比，不跨行业比较；趋势优先于截面数据（五年趋势比单期数值更重要）；任一硬门槛
不达标直接否决，不浪费时间深入分析。

## 判断流程（选股5步法）

1. **金字塔初筛**：选市场（A股/美股/港股独立筛选）+ 行业，看行业排名前10%，逐个点开
   雷达图（不要只看总分最高的）
2. **雷达图对比**：先ROE（五年平稳上升）→ 现金占比（五年年均≥10%）→ 毛利率/净利率
   （稳定且高于行业均值），可用对比功能叠加同行业两只
3. **五年趋势检查**：ROE是否逐年上升还是忽高忽低？经营现金流是否与净利润同步增长不大起
   大落？毛利率是否稳定或下滑？
4. **人工复核**：行业前景（朝阳/夕阳）、竞争地位（龙头/跟风者）、风险点（商誉过高/
   大股东减持/政策风险）
5. **加入观察池，等状态A**——现在还不能买，每月检查月K

## 决策规则

| 指标 | 门槛 |
|---|---|
| ROE | ≥20%（五年稳定/上升，同行业优先） |
| 毛利率 | ≥20%（最好≥30%） |
| 净利率 | ≥10% |
| 现金占总资产比 | ≥10%（≥20%优秀） |
| 经营现金流 | 为正且稳定增长 |

任一不达标 → 直接否决。

**边界规则：**
- 对外简化口径固定用"ROE≥20%"，19.7%这类接近门槛的情况不机械判不达标，要看行业与
  五年趋势（更精细的18~20%兜底带口径属人工分析层，不对外展开精确数值）
- 金融类例外：银行/保险/券商报表口径与实体企业不可比，默认不参与、不做开窗判定，
  即使技术面出现开窗信号也不入场

## 常见错误

- 只看金字塔总分最高的，跳过雷达图逐个核查——总分可能掩盖某项硬伤
- 拿雷达图截面数据当结论，忽略五年趋势（比如ROE单期高但逐年下滑）
- 基本面达标就直接买入——材料反复强调"现在还不能买"，选股只解决"买不买"，不解决
  "何时买"（见C/D模块）
- 把接近门槛的数值（如19.7%）机械判定不达标，没有结合行业和趋势综合判断
