# C. 择时-状态判定（状态A与开窗）

## 原始观点

材料反复强调一个高频误区的纠正：用户问"是不是状态A"，真正想问的常是"能不能入场"，
但两者是完全不同层级的概念——状态A是可持续数月甚至数年的"状态"，开窗是单次触发的
"事件"。这个区分被材料称为整章最高频的误区，说明 HOLDLE 方法论设计上刻意把"持续条件"
和"单次事件"分离，防止用户把"公司一直不错"误读成"随时能买"。

## 核心原则

固定口诀：**状态A持续 ≠ 可以入场。入场必须等"开窗"（绿转红/矮转高+柱≤DEA硬闸），
再切日K确认。状态看条件，开窗看事件。**

## 判断流程

### 状态A判定（逐项检查）
检查月K：① 双线（DIF/DEA）是否在0轴上方？② 柱子是否红柱？两者同时满足才是状态A。

### 开窗判定（逐级检查，缺一不可）
1. 柱子是否有状态变化：绿转红（负→正）或矮转高（缩短→伸长）？
2. 双线是否在0轴以上（DIF≥0且DEA≥0）？
3. 柱≤DEA（慢线）？→ 满足则开窗；柱>DEA则不开（视为高位追高）。DIF不参与本步判断

### 开窗前置：行情段自查（判断"新起点"还是"半路追高"）
1. 该标的自最近一次"按规则入场"后是否已有效出场（三阶止损/周K低点跌破）？
2. 当前是否持有该标未出场仓位？
3. 无在跑行情段且无持仓 → 本次开窗=新行情起点，可走标准流程
4. 有在跑行情段或已持有未出场 → 本次开窗=老行情半路=追高，不当新机会（已持有者
   继续按防守位管理，不加仓不二次入场）

> 补充：这一步判断依据是行情数据核对（最近一次入场→是否已出场），不是凭感觉猜测；
> 结论应先给出"新起点/半路追高"，再解释依据。

## 决策规则

**状态A判定表：**

| 双线位置 | 柱子颜色 | 是否状态A |
|---|---|---|
| ≥0轴 | 红柱 | 是 |
| ≥0轴 | 绿柱 | 否 |
| <0轴 | 红柱 | 否 |
| <0轴 | 绿柱 | 否 |

**开窗数值细则：**
- 柱子贴0轴（\|柱\|<0.5，含微正微负）→ 方向不可信，开窗判定上一律按绿柱处理，不算
  开窗；首个\|柱\|≥0.5的可信红柱月才是绿转红事件月；连续贴0轴顺延，不计入统计
- 次新股上市不足30个月 → 不参与判定（MACD统计量不足）
- 窗口只在事件发生的那个月K开一次；次月柱变矮 → 窗口立即关闭（基准=开窗月柱）；
  同一状态A段内，前窗关闭后可再开新窗（前窗已关闭+本次是新事件+位置仍干净）
- **"充分调整≥6月"已不再作为开窗判定要件**（现行口径）——矮转高是否构成开窗只看
  上面三条件，调整期长短只作参考不作拦截

**状态A形成的两种方式（数据呈现，非开窗门槛）：**

| 方式 | 定义 | 开窗特征 |
|---|---|---|
| 方式a | 双线先于柱子站上0轴 | 柱绿转红时双线已≥0，绿转红即开窗（最常见） |
| 方式b | 柱先于双线站上0轴（柱已红但双线仍<0） | 该"第一根红柱"不构成开窗——状态A尚未成立；须等双线补上0轴（状态A成立）后，柱子再次出现状态变化（且过柱≤DEA硬闸）才开窗，开窗月必然晚于第一根红柱 |

两种方式都过同一道闸（状态A成立+柱≤DEA），方式本身只是数据呈现，不是开窗门槛。

## 常见错误

1. **状态A≠开窗≠可以入场**：状态A可持续数月至数年（如药明康德2025年大部分时间
   处于状态A但柱持续变矮，全程观望不入场，直到矮转高+柱≤DEA才开窗）
2. **方式b误判①（正向）**：把"双线在水下+柱红=短暂反弹不参与"套到方式b上，得出
   "柱先上0轴=不参与"——错误，方式b是正常状态A形成路径，开窗与否看线柱关系
   （柱≤DEA），不是直接不参与
3. **方式b误判②（反向）**：柱子先转红但双线还没上0轴时，把这根"第一根红柱"当成
   开窗——错误，状态A尚未成立，这根红柱不构成开窗事件，需等双线补上0轴、柱子再
   出现新的状态变化才开窗。具体案例：某标的（美的2024段）柱先红→约18个月后双线
   才补上、状态A成立但仍无开窗事件→又过一段时间矮转高才真正开窗；该段即便开窗
   成立，日K入场条件也可能始终未触发（开窗≠入场，两者不矛盾）
4. **反例**：双线首次站上0轴但柱子没有状态变化（没有绿转红/矮转高）→ 不开窗，
   即使双线刚上0轴这个动作本身很显眼，也不构成开窗事件（事件资格只看柱子的状态
   变化+硬闸，不看双线本身的变化）
5. **行情段自查遗漏**：只看到"开窗信号出现"就当新机会，没检查该标是否已有在跑的
   行情段——老行情半路追高，位置不划算（不是公司不好）
