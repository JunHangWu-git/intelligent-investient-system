# G. 体系执行纪律

## 原始观点

材料的哲学收束句：不靠聪明靠规则，不靠速度靠耐心，不靠预测靠识别；规则的正确性由
时间验证，能走多远由执行纪律决定。这句话把前面选股/择时/管理三个模块串成一件事：
每个模块都是把"要不要判断/预测"的环节，替换成"检查条件是否满足"的环节。

**关于"23条规则清单"的澄清**：早期笔记（notes/06-system.md）提到知识库里有"23条
规则清单"未查到完整内容。本次二次查询（2026-09-19）用 holdle_get_rules 全量拉取
校准规则包，检索不到任何"23条"字样的清单结构——现行规则体系是以 §3.1~3.11 十一个
编号小节组织（对应本次拆解的 A~F+H 各模块内容），没有发现独立的"23条"清单。判断：
要么"23条清单"是更早版本的组织方式、后来被现有编号体系取代，要么指的是别的内部
文档。**不要再假设存在一份23条清单去索取**，现有 §3.x 结构就是当前最完整的规则来源。

## 核心原则

三把尺子各管一段，不能互相替代；该用哪把尺子由"买入前还是买入后"决定。

## 判断流程

```
买入前：月K管方向(状态A确认) → 日K管入场点(绿柱回撤→突破前高)
买入后：周K管出场(周K低点动态出场)，不再看月K
```

## 决策规则

| 尺子 | 管什么 | 什么时候用 |
|---|---|---|
| 月K | 方向：状态A确认、开窗判定 | 买入前 |
| 日K | 入场点：绿柱回撤→确认前高→突破前高买入，顺序固定不可反 | 买入前 |
| 周K | 出场：周K低点动态出场 | 买入后 |

**数据先行原则（本次查询新增，操作层硬规则）**：对任何"当前时点"的结论型判断
（能否入场/是否状态A/入场参考价/能否参与等），必须先拉取该标的实际行情数据
（月K/周K/日K，现状判断用前复权）核对，再给结论——不能跳过数据直接凭经验/记忆
判断。这条规则对应到本项目 Phase 2 写策略代码时，意味着任何信号判断函数都应该
以实际K线数据为输入，不能有"跳过取数直接返回结论"的分支。

## 常见错误

- 已入场后还想用月K信号做出场判断——违反"三把尺子各管一段"，出场只认周K
- 把"23条规则清单"当成还没查到的既定事实反复索取——现有材料没有这份清单，见上方
  "原始观点"澄清
- 判断个股当前状态时跳过实际数据核对，直接凭对该公司的历史印象下结论——违反数据
  先行原则
