# F. 出场规则（周K低点动态出场）

## 原始观点

材料明确"无主动止盈"——不设"涨到X%就卖"的目标位。出场只认两件事：三阶止损
（见E模块）+ 周K低点动态出场。这个设计的意图是"吃完整段主升浪"，不赌顶，让出场
时机跟着市场走而不是跟着一个提前设定的价格数字走。

## 核心原则

有效低点随创新高逐级抬高，出场参考价跟随上移，不赌顶不主动止盈；最终跌破最近一个
周K低点才卖出。

## 判断流程

1. 入场后切换到周K
2. 跟踪是否形成"有效低点"：周K出现绿柱且创新高后的低点，且该低点>入场价，才作为
   出场参考
3. 有新的创新高+绿柱出现 → 有效低点可再次上调（逐级抬高，可多次）
4. 检查最近一个周K有效低点是否被跌破：未破→继续持有；跌破→按规则卖出
5. 卖出后等下一次状态A（回到C模块，重新开始判定流程）

## 决策规则

- 有效低点 = 周K出现绿柱且创新高后的低点；低点必须>入场价才算数
- 跌破最近一个周K有效低点 → 卖出
- 未入场前看月K→日K（等待池）；已入场后只看周K（持有池），不再关心月K状态A变化

## 常见错误

- 涨了很多（比如翻倍）就想卖——材料明确"涨幅不是卖出理由"，只看周K低点是否被
  跌破，没破就继续持有
- 周K低点跌破卖出后又涨了，去追高——材料态度是"规则触发就执行，不要因为卖飞去
  追高，等新的状态A再考虑重新入场"
- 已入场后还在看月K状态A变不变（柱转绿/变矮）就想提前离场——已入场后月K不再是
  判断依据，只看周K
