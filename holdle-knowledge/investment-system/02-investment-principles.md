# 投资理念 — 核心方法论总纲

> 本文档是整套方法论的地图：怎么选、怎么等、怎么管，三件事怎么串成一条流水线。
> 每一步的详细判断规则在对应的专门文件里，本文档只给结构和入口。

## 三层结构：选股→择时→管理

| 阶段 | 解决的问题 | 输入 | 输出 | 详见文件 |
|---|---|---|---|---|
| 选股 | 这家公司值不值得买 | 同行业候选公司财务数据 | 加入观察池的候选股票 | 《04-企业分析体系》 |
| 择时 | 现在是不是买的好时机 | 观察池标的 | 入场时点+入场参考价 | 《03-状态A与买入时机判断体系》 |
| 管理 | 买入之后怎么办 | 已买入的持仓 | 风险受控的持仓与退出 | 《05-交易管理规则》 |

三阶段是顺序流水线，不能跳步：没过企业质量门槛的公司不进观察池；没进观察池的
标的不判断状态A；没走完入场流程（状态A→开窗→行情段自查→日K绿柱→突破）不买入；
买入前用月K/日K判断，买入后只用周K管理。完整可视化版本见《06-入场决策流程图》。

## 周期分工总纲（三把尺子）

| 尺子 | 管什么 | 什么时候用 |
|---|---|---|
| 月K | 方向：状态A确认、开窗判定 | 买入前 |
| 日K | 入场点：绿柱回撤→确认前高→突破前高买入，顺序固定不可反 | 买入前 |
| 周K | 出场：周K低点动态出场 | 买入后 |

该用哪把尺子由"买入前还是买入后"决定，不能互相替代——已入场后不再看月K状态A
变化（"入了门就不看月K的门铃"）。

## 完整流程一句话版

```
选股5步法 → 加入观察池 → 每月检查状态A
  → 状态A成立 → 检查开窗三条件 → 开窗前先查行情段(新起点/老行情半路)
    → (新起点) 切日K → 找绿柱日 → 算参考价 → 等突破 → 买入+设初始止损
      → 切周K管理 → 三阶止损 + 周K有效低点动态出场
        → 触发出场 → 卖出 → 回到"每月检查状态A"循环
```

## 贯穿全流程的操作纪律：数据先行

任何"当前时点"的结论型判断（能否入场/是否状态A/入场参考价/能否参与等），必须
先拉取该标的实际行情数据（月K/周K/日K；现状判断用前复权，历史复盘用后复权）
核对，再给结论——不允许跳过数据直接凭经验/记忆下判断。写策略代码时，这条应该
落实成"信号判断函数必须以实际K线数据为输入"，不能有"跳过取数直接返回结论"的
分支。
