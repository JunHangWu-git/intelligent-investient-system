# 入场决策流程图（全流程）

> ◇ = 判断点；[ ] = 结果/动作；→ 沿流水线往下走。

```
┌─────────────────────────────────────────────────────────────────┐
│【企业分析体系】详见 04-enterprise-analysis-system.md                │
└─────────────────────────────────────────────────────────────────┘
┌────────────────┐
│ 金字塔初筛        │  同行业前10%，逐个看雷达图
└────────┬─────────┘
         ▼
┌────────────────┐
│ 雷达图+五年趋势   │  ROE≥20% 毛利≥20% 净利≥10% 现金占比≥10% 现金流稳增
└────────┬─────────┘
         ▼
   ◇ 任一门槛不达标？──是──→ [直接否决，退出]
         │否
         ▼
┌────────────────┐
│ 人工复核          │  行业前景 / 竞争地位 / 风险点
└────────┬─────────┘
         ▼
┌────────────────┐
│ 加入观察池        │ ←── 卖出后的标的也回到这里，等下一次状态A
└────────┬─────────┘
         │ 每月检查月K
         ▼
┌─────────────────────────────────────────────────────────────────┐
│【状态A与买入时机判断体系】详见 03-state-a-entry-timing-system.md     │
└─────────────────────────────────────────────────────────────────┘
   ◇ 状态A成立？(月K双线≥0轴 且 柱子红) ──否──→ [继续观察池等待]
         │是
         ▼
   ◇ 开窗三条件全过？
     ① 柱子有状态变化(绿转红/矮转高)
     ② 双线≥0轴(DIF且DEA)
     ③ 柱≤DEA硬闸                    ──任一不过──→ [不开窗，继续观察池等待]
         │全过
         ▼
   ◇ 行情段自查：该标有在跑的行情段？ ──有──→ [老行情半路=追高，不当新机会]
         │无(新起点)                            (已持有则按防守位管理，不加仓)
         ▼
┌────────────────┐
│ 切日K            │  开窗次月
└────────┬─────────┘
         ▼
┌────────────────┐
│ 找绿柱日          │  切日K月第一天起，第一个柱<0交易日
└────────┬─────────┘      (不可从月末往回找/不可取最近红转绿日/不可取最近绿柱段起点)
         ▼
┌────────────────┐
│ 算参考价          │  [开窗月首日, 绿柱日] 闭区间日K最高
└────────┬─────────┘
         ▼
   ◇ 突破参考价？(绿柱日后首个盘中high>参考价) ──否──→ [继续等]
         │是                                     (超5%不追 / 50-60天入场失效)
         ▼
┌────────────────┐
│ 买入              │  买入价=参考价；同时设初始止损=入场价-20%
└────────┬─────────┘
         ▼
┌─────────────────────────────────────────────────────────────────┐

└─────────────────────────────────────────────────────────────────┘
┌────────────────┐
│ 切周K管理         │  只做两件事：查止损 + 追周K有效低点
└────────┬─────────┘      (入场后不再看月K状态A变化)
         ▼
   ◇ 三阶止损触发？(-20%/-10%/保本，单向只上不下) ──是──→ [卖出，回到观察池]
         │否
         ▼
   ◇ 周K有效低点跌破？(绿柱+创新高后的低点>入场价) ──是──→ [卖出，回到观察池]
         │否
         ▼
   [继续持有；有效低点随创新高逐级上调，不赌顶不主动止盈]
```

## 决策条件速查表

| 检查点 | 通过条件 | 不通过 → |
|---|---|---|
| 企业质量 | ROE≥20% 毛利率≥20% 净利率≥10% 现金占比≥10% 现金流为正且稳增 | 直接否决 |
| 状态A | 月K双线≥0轴 且 柱子红（"且"非"或"） | 继续观察 |
| 开窗 | 柱状态变化 + 双线≥0轴 + 柱≤DEA，三条全过 | 继续观察 |
| 行情段自查 | 无在跑行情段 且 无持仓 = 新起点 | 半路追高，跳过本次 |
| 日K突破 | 盘中high>参考价，且在5%/50-60天有效期内 | 继续等 / 入场失效 |
| 止损 | 现价未破三阶止损线 | 跌破 → 卖出 |
| 出场 | 现价未破周K有效低点 | 跌破 → 卖出 |

## 三把尺子对照（各阶段用哪根K线）

| 阶段 | 用哪根K线 |
|---|---|
| 状态A判定、开窗判定 | 月K |
| 绿柱日、参考价、突破 | 日K |
| 止损检查、有效低点跟踪 | 周K |
