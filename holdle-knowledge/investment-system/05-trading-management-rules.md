# 交易管理规则 — 怎么控制风险

> 本文档回答"买入之后怎么办"。前提：已经按《03-状态A与买入时机判断体系》完成
> 入场。

## 核心原则

一次性建仓，不加仓不补仓不越跌越买摊成本；止损单向调整只上不下；不赌顶不主动
止盈，吃完整段主升浪。

## 建仓纪律

- **分散持仓**：5-8只跨行业等权重
- **一次性建仓**：状态A+开窗+突破 → 一次性买入分配额度，同时设初始止损（入场价-20%）
- **禁止动作清单**：加仓、补仓、越跌越买摊成本、一把梭重仓——一律禁止
- 资金量很小时可按资金量级适当减少持仓数量，但真正风险是"一次亏光"不是
  "赚得慢"

## 入场后管理：只做两件事

```
入场 → 切换到周K
         ├─ 检查止损是否触发（三阶止损，见下表）
         └─ 跟踪周K有效低点（有绿柱+创新高，见下方）
已入场后不再关心月K状态A变化（柱变矮/转绿不影响持有池）
```

## 三阶止损（单向调整，只上不下）

| 阶段 | 止损线 |
|---|---|
| 未盈利 | 入场价-20% |
| 涨超20% | 入场价-10% |
| 涨超30% | 入场价（保本） |

止损是保险不是预测——止损10次可能3次是假跌破，但另外7次救了大命。止损后又涨了
就接受它，不追悔，等下次机会。**止损线只能上调，不能下调**——跌破后"再给一次
机会"是违规操作。

## 周K低点动态出场

1. 跟踪是否形成"有效低点"：周K出现绿柱且创新高后的低点，且该低点>入场价，
   才作为出场参考
2. 有新的创新高+绿柱出现 → 有效低点可再次上调（逐级抬高，可多次）
3. 检查最近一个周K有效低点是否被跌破：未破→继续持有；跌破→按规则卖出
4. 卖出后等下一次状态A（回到《04-企业分析体系》/《03-状态A与买入时机判断体系》
   重新开始判定流程）

无主动止盈——不设"涨到X%就卖"的目标位，涨幅不是卖出理由，只看周K低点是否
被跌破。

## 常见错误

- 止损后又涨了就后悔/怀疑规则——止损是保险不是预测，接受它
- 系统性风险下觉得分散持仓失效——无法完全规避系统性风险，但损失不会集中在
  单只上，止损规则会自动触发，不会全仓套牢
- 把止损线往下调（比如跌破后"再给它一次机会"）——违反单向只上不下的硬规则
- 越跌越买摊低成本——明确列入禁止动作清单，不是"谨慎加仓"的灰色地带
- 涨了很多（比如翻倍）就想卖——涨幅不是卖出理由，只看周K低点是否被跌破
- 周K低点跌破卖出后又涨了，去追高——规则触发就执行，等新的状态A再考虑重新
  入场
- 已入场后还在看月K状态A变不变（柱转绿/变矮）就想提前离场——已入场后月K
  不再是判断依据，只看周K
