# 状态A与买入时机判断体系

> 本文档回答"现在能不能买"。前提：标的已经通过《04-企业分析体系》的企业质量
> 门槛，在观察池里。

## 总纲：三层递进，缺一不可

```
状态A（持续条件） → 开窗（单次事件） → 日K入场（具体点位）
   月K双线+柱≥0轴      绿转红/矮转高       绿柱回撤→突破参考价
   可持续数月至数年      +柱≤DEA硬闸         买入的最后一步
```

固定口诀：**状态A持续 ≠ 可以入场。入场必须等"开窗"，再切日K确认。状态看条件，
开窗看事件。**

问"是不是状态A"时，真正要判断的常常是"能不能买"——这是最高频的误区，两者必须
分开判断，不能划等号。

## 第一步：状态A判定

检查月K：① 双线（DIF/DEA）是否在0轴上方？② 柱子是否红柱？两者同时满足（"且"
不是"或"）才是状态A。

| 双线位置 | 柱子颜色 | 是否状态A |
|---|---|---|
| ≥0轴 | 红柱 | 是 |
| ≥0轴 | 绿柱 | 否 |
| <0轴 | 红柱 | 否 |
| <0轴 | 绿柱 | 否 |

**状态A形成的两种方式**（数据呈现，不是开窗门槛）：

| 方式 | 定义 | 特征 |
|---|---|---|
| 方式a | 双线先于柱子站上0轴 | 柱绿转红时双线已≥0，绿转红即开窗（最常见） |
| 方式b | 柱先于双线站上0轴（柱已红但双线仍<0） | "第一根红柱"不构成开窗——需等双线补上0轴后，柱子再出现新的状态变化才开窗 |

## 第二步：开窗判定（逐级检查，缺一不可）

1. 柱子是否有状态变化：绿转红（负→正）或矮转高（缩短→伸长）？
2. 双线是否在0轴以上（DIF≥0且DEA≥0）？
3. 柱≤DEA（慢线）？→ 满足则开窗；柱>DEA则不开（高位追高）。DIF不参与本步判断

**补充数值细则：**
- 柱子贴0轴（|柱|<0.5，含微正微负）→ 方向不可信，一律按绿柱处理，不算开窗；
  首个|柱|≥0.5的可信红柱月才是绿转红事件月；连续贴0轴顺延，不计入统计
- 次新股上市不足30个月 → 不参与判定
- 窗口只在事件发生的那个月K开一次；次月柱变矮 → 窗口立即关闭（基准=开窗月柱）；
  同一状态A段内，前窗关闭后可再开新窗
- "充分调整≥6月"已不再作为开窗判定要件——只看上面三条件，调整期长短只作参考

## 第三步：开窗前置检查——行情段自查

判断这次开窗是"新起点"还是"老行情半路追高"：

1. 该标的自最近一次"按规则入场"后是否已有效出场（三阶止损/周K低点跌破）？
2. 当前是否持有该标未出场仓位？
3. 无在跑行情段且无持仓 → 新行情起点，可走标准流程
4. 有在跑行情段或已持有未出场 → 老行情半路=追高，不当新机会（已持有者继续按
   防守位管理，不加仓不二次入场）

> 判断依据是行情数据核对，不是凭感觉；结论应先给出"新起点/半路追高"，再解释依据。

## 第四步：日K入场流程（开窗后，是新起点时才走）

```
① 开窗次月，切日K
② 找"绿柱日"（见下方机械定义）
③ 算参考价 = [开窗月首日, 绿柱日] 闭区间日K最高
④ 等突破：绿柱日后首个盘中high > 参考价 → 买入，买入价按参考价记录
⑤ 买入同时设初始止损：入场价-20%
⑥ 切周K，转入《05-交易管理规则》
```

**绿柱日机械定义（严格按此查找，不凭感觉）：**

从开窗次月第一个交易日起，按日期升序扫日K，取**柱<0交易日中日期最早者**。只看
柱的符号，不看幅度，不判断是否连续成段（单日MACD柱<0即成立，哪怕次日转红）；
无论当月绿柱分几段、中间夹几根红柱，都取日期最早的柱<0交易日。切日K月全月无
柱<0 → 顺延至其后首个柱<0交易日。

**三条反向禁令（禁止用这些方法找绿柱日）：**
1. 禁止从月末/当前往回找
2. 禁止取"最近一次红转绿"事件日
3. 禁止取"离今天最近的一段绿柱"的起点

> 注：月K开窗判定的"贴0轴不算数"规则不适用于这里——日K绿柱只看符号，柱<0
> （哪怕只有-0.04）就是绿柱。

**错过与失效：**
- 超过参考价约5%不追，等下一次
- 50-60天不突破 → 入场失效

## 数据准备：复权口径选择

| 场景 | 用哪种 |
|---|---|
| 问"现在/当前/近期/是否状态A/入场参考价"等现状判断 | 前复权（forward） |
| 复盘/回测/历史区间/当时/上市以来/第一次入场/上次入场 | 后复权（backward） |
| 未明确表达"要回顾历史区间"的 | 一律前复权（宁可前复权，不要默认后复权） |
| 同一次分析里历史事件+当前价并存 | 历史用后复权，当前价用前复权，分别注明 |

判据是"有没有明确的历史区间意图"，不是看提问带没带年份数字。意图从"现状"转到
"历史区间"（或反向）时，必须用对应口径重新取数，不能复用已拉取的数据。

## 常见错误

1. **状态A≠开窗≠可以入场**：状态A可持续数月至数年（如某标的2025年大部分时间
   处于状态A但柱持续变矮，全程观望不入场，直到矮转高+柱≤DEA才开窗）
2. **方式b误判①（正向）**：把"双线在水下+柱红=短暂反弹不参与"套到方式b上，
   得出"柱先上0轴=不参与"——错误，方式b是正常形成路径，开窗与否看线柱关系
3. **方式b误判②（反向）**：柱子先转红但双线还没上0轴时，把这根"第一根红柱"
   当成开窗——错误，需等双线补上0轴、柱子再出现新的状态变化才开窗。实际案例：
   某标的柱先红→约18个月后双线才补上、状态A成立但仍无开窗事件→又过一段时间
   矮转高才真正开窗；该段即便开窗成立，日K入场条件也可能始终未触发
4. **反例**：双线首次站上0轴但柱子没有状态变化 → 不开窗，双线变化本身不算事件
5. **行情段自查遗漏**：看到开窗信号就冲，没检查该标是否已有在跑的行情段
6. **绿柱日反向禁令违反**：按"最近一次红转绿"或"离今天最近的绿柱段起点"去找
7. **复权口径混用**：现状判断误用后复权（或漏传参数用了默认值），导致算出的
   当前价与实际行情软件对不上
8. **追高/超期不追违反**：超参考价5%还追，或50-60天窗口过了还在等
