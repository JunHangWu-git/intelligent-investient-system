# 企业分析体系 — 怎么选好公司

> 本文档回答"这家公司值不值得买"，解决的是第一层概率优势（企业质量）。不解决
> "什么时候买"——那是《03-状态A与买入时机判断体系》的事。高分只说明基本面好，
> 不代表价格合适，通过本体系筛选出的公司只能进观察池，不能直接买入。

## 核心原则

- 同行业对比，不跨行业比较
- 趋势优先于截面数据——五年趋势比单期数值更重要
- 任一硬门槛不达标 → 直接否决，不浪费时间深入分析

## 选股5步法

```
① 金字塔初筛
    选市场(A股/美股/港股独立筛选) + 行业(必须同行业对比)
    看行业排名前10%，逐个点开雷达图(不要只看总分最高的)
        ↓
② 雷达图对比
    ROE(五年平稳上升) → 现金占比(五年年均≥10%) → 毛利率/净利率(稳定且高于行业均值)
    可用对比功能叠加同行业两只公司
        ↓
③ 五年趋势检查
    ROE逐年上升还是忽高忽低? 经营现金流是否与净利润同步增长不大起大落?
    毛利率是否稳定或下滑? 标准: 各项指标平稳或持续向好
        ↓
④ 人工复核
    行业前景(朝阳/夕阳) 竞争地位(龙头/跟风者) 风险点(商誉过高/大股东减持/政策风险)
        ↓
⑤ 加入观察池, 等状态A
    现在还不能买——每月检查月K, 等状态A出现
```

金字塔不替你选股，只帮你缩小范围，整个初筛过程约半小时到一小时。

## 企业质量量化门槛（决策规则）

| 指标 | 门槛 |
|---|---|
| ROE | ≥20%（五年稳定/上升，同行业优先） |
| 毛利率 | ≥20%（最好≥30%） |
| 净利率 | ≥10% |
| 现金占总资产比 | ≥10%（≥20%优秀） |
| 经营现金流 | 为正且稳定增长 |

**任一不达标 → 直接否决。**

**边界规则：**
- 对外简化口径固定用"ROE≥20%"；19.7%这类接近门槛的情况不机械判不达标，要看
  行业与五年趋势（更精细的18~20%兜底带口径属人工分析层，不做精确数值展开）
- **金融类例外**：银行/保险/券商报表口径与实体企业不可比，默认不参与、不做
  开窗判定，即使技术面出现开窗信号也不入场

## 常见错误

- 只看金字塔总分最高的，跳过雷达图逐个核查——总分可能掩盖某项硬伤
- 拿雷达图截面数据当结论，忽略五年趋势（比如ROE单期高但逐年下滑）
- 基本面达标就直接买入——选股只解决"买不买"，不解决"何时买"
- 把接近门槛的数值（如19.7%）机械判定不达标，没有结合行业和趋势综合判断
