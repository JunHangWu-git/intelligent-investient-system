# 状态A精确定义

状态A = 月K线 MACD 双线（DIF/DEA）在0轴上方 + 柱子（红柱）在0轴上方，两者同时
满足（"且"不是"或"）。

| 双线位置 | 柱子颜色 | 是否状态A |
|---|---|---|
| ≥0轴 | 红柱 | 是 |
| ≥0轴 | 绿柱 | 否 |
| <0轴 | 红柱 | 否 |
| <0轴 | 绿柱 | 否 |

## 高频误区：状态A ≠ 开窗 ≠ 可以入场

状态A是**状态**（持续条件，可维持数月甚至数年）；开窗是**事件**（单次触发：绿转红
/矮转高发生的那个月K + 柱≤DEA硬闸）。

固定口诀：状态A持续 ≠ 可以入场。入场必须等"开窗"，再切日K确认。状态看条件，开窗
看事件。

案例：药明康德2025年大部分时间处于状态A，但柱子持续变矮，全程观望不入场，直到
矮转高+柱≤DEA才开窗。
