# 开窗三条件（逐级检查，缺一不可）

1. 硬性：柱子有状态变化 — 绿转红（负→正）或矮转高（缩短→伸长）
2. 硬性：双线在0轴以上 — DIF≥0 且 DEA≥0
3. 统一硬闸：柱≤DEA（慢线） — 柱≤DEA → 开窗；柱>DEA → 不开（高位追高）。DIF 不
   参与此判断

## 补充规则

- 柱子贴0轴（|柱|<0.5，含微正微负）→ 方向不可信，开窗判定上一律按绿柱处理，不算
  开窗；首个|柱|≥0.5的可信红柱月才是绿转红事件月
- 次新股上市不足30个月不参与（MACD统计量不足）
- 窗口只在事件发生的那个月K开一次，后续柱子继续升高不是新窗口
- 次月柱变矮 → 窗口立即关闭（基准=开窗月柱）
- 同一状态A段内，前窗关闭后可再开新窗（前窗已关闭+本次是新事件+位置仍干净）

## 开窗前先查行情段

判断能不能当新机会前先确认：该标的是否已有"按规则买入、还没卖出"的行情段在跑？
- 是 → 现在再开窗=老行情半路=追高，不建议当新买入
- 否 → 本次开窗=新行情起点，可走标准流程
