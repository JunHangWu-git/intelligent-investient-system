# 入场决策流程（6步）

```
① 状态A确认（月K双线+柱≥0轴）
② 次月切日K
③ 等日K高点 + 回撤
④ 日K MACD 绿柱确认回撤（绿柱前最高价 = 入场参考价）
⑤ 突破前高 = 买入（同时设止损：入场价-20%）
⑥ 切周K出场管理（周K低点动态出场）
```

## 关键规则

- 参考价 = [开窗月首日, 绿柱日] 闭区间日K最高（不看柱色）
- 突破 = 绿柱日后首个盘中 high > 参考价；买入价按参考价记录
- 错过不追：超过入场参考价约5%不追，等下一次
- 50-60天不突破 → 入场失效
- 未入场前看月K→日K（等待池）；已入场后只看周K（持有池）
