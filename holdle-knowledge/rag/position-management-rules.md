# 分散持仓 / 一次性建仓

- 5-8只跨行业等权重
- 不加仓、不补仓、不越跌越买摊成本、一把梭重仓 = 一律禁止
- 资金量很小时可按资金量级表适当减少持仓数量；真正的风险不是"赚得慢"，是一次亏光
- 系统性风险下无法完全规避（所有股票一起跌），但损失不会集中在单只上，止损规则
  会自动触发，不会全仓套牢

## 管理规则速查图

```
5-8只跨行业等权重分仓
    → 每只独立等待月线状态A
        → 状态A出现，一次性买入分配额度
            → 设初始止损：入场价-20%
                → 切换到周K线
                    ┌─ 亏损阶段：三级止损（-20%→-10%→保本）
                    └─ 盈利+有效低点：周K低点动态出场
                        → 跌破出场价则卖出，未破则持有
                            → 卖出后等下一次状态A
```
