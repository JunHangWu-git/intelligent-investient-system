## 目的

把 `notes/` + `rag/` 里的转述笔记，进一步拆成「原始观点 / 核心原则 / 判断流程 /
决策规则 / 常见错误」五栏结构化内容，方便以后写策略代码（Phase 2 MACD/state-A
信号逻辑）时直接照规则办事，而不是靠读长文背课文。

## 1. 大模块划分（7块）

```
A 认知信念层     (为什么这套方法成立 — ch1 + ch6哲学收束)
B 选股规则       (企业质量门槛+流程 — ch2)
C 择时-状态判定  (状态A/开窗判定 — ch3前半)
D 择时-入场执行  (日K流程/参考价/突破 — ch3后半)
E 持仓管理       (止损/仓位/建仓纪律 — ch4前半)
F 出场规则       (周K动态出场 — ch4后半)
G 体系执行纪律   (周期分工三把尺子+规则清单占位 — ch6)
+ 常见错误库(H)  跨模块单独汇总，不归某一章
```

拆分理由：
- C（状态判定：要不要关注）和 D（入场执行：具体怎么下手）决策粒度不同，
  分开存放便于以后按需读取（例如写扫描器只需要C，写下单辅助才需要D）。
- E（建仓/止损纪律）和 F（周K出场判定）同理，一个是静态规则一个是动态跟踪逻辑。
- H 单独建索引，汇总各模块「常见错误」栏，方便以后交叉检索「我是不是又踩了这坑」。

## 2. 每模块提取的五栏定义

| 栏目 | 提取内容 |
|---|---|
| 原始观点 | HOLDLE 底层信念/论证逻辑——「为什么这么设计」，不是规则本身 |
| 核心原则 | 一句话总纲 |
| 判断流程 | 有序步骤/checklist，能直接照走 |
| 决策规则 | 具体数值门槛/硬闸条件，能直接写成 if-then |
| 常见错误 | 已知误判案例 + 正确纠正说法 |
