# 第2章 选股篇

> 转述整理，非课程原文。详见 [../README.md](../README.md) 免责声明。

## 核心原则

把"看什么指标"（雷达图六维+排序）和"用什么工具"（金字塔）串成一套流程，从海量股票
中筛出值得跟踪的候选股票（观察池），构建第一层概率优势（企业质量）。

金字塔**不替你选股，只帮你缩小范围**：选行业 → 看排名前10% → 逐个点开看雷达图 →
把不错的加入观察池。整个过程约半小时到一小时。

## 选股5步法

| 步骤 | 操作 | 产出 |
|---|---|---|
| 1. 金字塔初筛 | 选市场（A股/美股/港股，各自独立筛选）+ 行业，**必须同行业对比，不跨行业**；不要只看总分最高的，先看行业排名前10%，逐个点进看雷达图 | 候选公司列表 |
| 2. 雷达图对比 | 先看 ROE（五年是否平稳上升？低的直接淘汰）；再看现金占比（五年年均≥10%？低则风险偏高）；再看毛利率/净利率（是否稳定且高于行业均值）；用对比功能把两只同行业公司叠加看 | 初步通过名单 |
| 3. 五年趋势检查 | 雷达图是截面数据，趋势更重要：ROE 是逐年上升还是忽高忽低？经营现金流是否与净利润同步增长、不大起大落？毛利率是否稳定或下滑？通过标准：各项指标平稳或持续向好 | 通过名单 |
| 4. 人工复核 | 数据反映不了的用判断力：行业前景（朝阳/夕阳）、行业竞争地位（龙头/跟风者）、风险点（商誉过高、大股东减持、政策风险） | 备选池 |
| 5. 加入观察池，等状态A | **现在还不能买**——金字塔高分只说明基本面好，不代表价格合适；基本面好+价格高，买入也可能被套。加入观察池，每月检查月K，等状态A出现 | 候选池 |

## 企业质量量化门槛（对外简化口径）

- ROE ≥ 20%（五年稳定/上升，同行业优先）
- 毛利率 ≥ 20%（最好 ≥30%），净利率 ≥ 10%
- 现金占总资产比 ≥ 10%（≥20% 优秀）
- 经营现金流为正且稳定增长
- 不达标 → 直接否决

阈值不死板：19.7% 这类接近门槛的情况不机械判不达标，要看行业与五年趋势（更精细的
兜底带口径属导师人工分析层，对外维持"ROE≥20%"简化表述）。

**金融类例外**：银行/保险/券商报表口径与实体企业不可比，默认不参与、不做开窗判定。
