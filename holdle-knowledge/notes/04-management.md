# 第4章 管理篇

> 转述整理，非课程原文。详见 [../README.md](../README.md) 免责声明。

## 管理规则全表（速查版）

```
5-8只跨行业等权重分仓
    → 每只独立等待月线状态A
        → 状态A出现，一次性买入分配额度
            → 设初始止损：入场价-20%
                → 切换到周K线
                    ┌─ 亏损阶段：百分比三级止损（-20% → -10% → 保本，单向调整）
                    └─ 盈利+周K有效低点形成：周K低点动态出场（绿柱确认+创新高）
                        → 跌破出场价则卖出，未破则持有
                            → 卖出后等下一次状态A
```

## 入场后管理（持有池视角）

已入场后切换到周K，此后只做两件事：① 检查止损是否触发 ② 跟踪周K有效低点。

| 管理项 | 规则 |
|---|---|
| 仓位 | 一次性建仓，不加仓不补仓不越跌越买 |
| 止损 | 三阶止损：未盈利→入场价-20%；涨超20%→入场价-10%；涨超30%→入场价（保本），单向调整只上不下 |
| 出场 | 周K形成有效低点（有绿柱+创新高）且低点>入场价 → 切周K动态出场；未破继续持有，跌破卖出 |
| 月K信号 | 已入场后不再关心月K状态A变化（柱变矮/转绿不影响持有池） |

有效低点随创新高逐级抬高（可多次上调），出场参考价跟随上移——不赌顶、不主动止盈，
吃完整段主升浪。最终跌破最近一个周K低点才卖出。

## 分散持仓 / 一次性建仓

- 5-8只跨行业等权重
- 不加仓、不补仓、不越跌越买摊成本
- 资金量很小时可按资金量级表适当减少持仓数量，真正风险不是"赚得慢"，是一次亏光

## 常见问答（实战篇 Q11-Q15，与管理直接相关）

- **止损后又涨了怎么办**：接受它。止损是保险不是预测。止损10次可能3次是假跌破，
  但另外7次救了大命。
- **系统性风险下分散持仓失效怎么办**：无法完全规避系统性风险，但损失不会集中在
  单只上；止损规则会自动触发，不会全仓套牢。
- **周K低点跌破卖出后又涨了怎么办**：规则触发就执行，不要因为卖飞去追高，等新的
  状态A再考虑重新入场。
- **涨了100%要不要卖**：看周K低点，没破就继续持有，涨幅不是卖出理由。
