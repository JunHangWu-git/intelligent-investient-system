# HOLDLE 方法论学习笔记

来源：`mcp__holdle-ai` 知识库检索（`holdle_ask`/`holdle_get_rules`），2026-09-19 整理。

## 说明（务必先看）

- **不是课程原文**。这里是转述整理的方法论要点，不是逐字复制的课程内容——HOLDLE
  自己的工具规则禁止逐字复述/大段输出课程原文（保护课程版权），这份笔记遵守该规则。
- **规则会变**。HOLDLE 方法论口径会持续校准（本次抓取时是 v1.21，2026年9月内已改过
  6次）。这份笔记是抓取当天的快照，涉及具体个股判断/精确数值时，应该用
  `mcp__holdle-ai__holdle_ask` 再查一次当前口径，不要只信这份笔记。
- **概念性内容**（状态A定义、开窗三条件这类基本不常变的）可以直接参考笔记回答。
- 人称口径：概念定义一律归 HOLDLE，不归属笔记整理者或提问者。

## 结构

- `notes/` — 按章节整理的可读笔记（7章，第7章内容知识库未单独收录，见该文件说明）
- `rag/` — 按概念切块的检索友好版，每个文件一个独立概念，带 frontmatter
  （chapter/tags/source），方便 agent 用关键词或简单检索定位
- `decomposition/` — 按「原始观点/核心原则/判断流程/决策规则/常见错误」五栏结构
  二次拆解的版本（A-H共8个模块文件+INDEX.md），2026-09-19 生成，供以后写 Phase 2
  策略代码时直接照规则办事用。拆解计划见 `decomposition-plan.md`。
- `investment-system/` — 在 decomposition/ 基础上整合成的完整投资体系六件套
  （投资哲学/投资理念/状态A与买入时机判断体系/企业分析体系/交易管理规则/入场
  决策流程图），2026-09-19 生成，面向"任何AI读到都能一步步判断"的可执行文档。
- `training-log/` — 实战考核纠正记录（"先自己判断→对比holdle_ask校对→记录错在哪/
  为什么错/怎么避免→重做"的训练流程留痕），文件命名`纠正记录_第N条_<股票名>.md`，
  2026-09-19 起累积。
